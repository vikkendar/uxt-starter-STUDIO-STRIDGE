Print No. 01

Ground Origami

The first print in the Stridge catalogue folds a bird from a single unbroken line — the same crease logic used to fold a sheet of paper, redrawn in one stroke of cobalt on heavy cotton.

It sits small on the chest, four inches square, printed once per garment. Every piece is finished with a woven tag at the neck, marking it as part of the run.

About

The studio

Studio Stridge is a small apparel studio working one drop at a time. Each release pairs a single print with two silhouettes — a tee and a hoodie — cut heavy, tagged by hand, and retired once the run sells out.

We'd rather make a short run well than a long run fast. No restocks, no filler colorways — just the next print, when it's ready.
